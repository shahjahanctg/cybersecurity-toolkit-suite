# data/wordlists — demo data only

These tiny lists exist for **unit tests and tool demos**. They contain no
credentials, API keys, or sample malware.

Usage:
- The wordlist directory is configurable (Settings → Wordlist directory).
- For authorized password-audit work, use wordlists your organization is
  licensed to use (e.g. a rockyou sample you hold rights to) — do not ship them
  inside this repository.

Place plain-text lists here, one entry per line:

```
usernames.txt
passwords.txt
```
